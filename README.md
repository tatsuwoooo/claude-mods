# claude-mods

Claude Code 用の自作 mod をまとめたもの。

- **トークン使用量ペイン**：コンテキスト使用量・累計コスト・5時間／週間の利用枠を表示。`/tokens` で開く。よく使うコマンドのボタン付き
- **スクショ**：チャット欄の上のボタン。クリックしたウィンドウを撮って範囲を選び、クリップボードへコピー（Windows）
- **リモート**：チャット欄の上のボタン。押すとそのセッションのリモートコントロールをオンにする

## インストール

ターミナルの Claude Code で:

```
/plugin install claude-mods --marketplace tatsuwoooo/claude-mods
```

シェルから:

```
claude plugin install claude-mods --marketplace tatsuwoooo/claude-mods
```

デスクトップアプリ（`/plugin` が使えない場合）: 入力欄の横の + → Plugins → Add marketplace に `tatsuwoooo/claude-mods` → Add plugin
